Q197 — family EXPLAIN QUERY PLAN and index aware queries, scenario 7: auto-index-for-unique-constraint

Task
Create t2(x TEXT UNIQUE) and explain SELECT * FROM t2 WHERE x='a'. Observe the persistent index SQLite creates to enforce UNIQUE (sqlite_autoindex_t2_1), rather than a table scan. This constraint index is not a transient query-time automatic index.

Dialect: SQLite, executed with Node node:sqlite DatabaseSync. SQLite date/string functions, dynamic typing, rowid/INTEGER PRIMARY KEY, booleans-as-integers, PRAGMAs and query-plan text are SQLite-specific, not portable SQL promises.
