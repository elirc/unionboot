Q155 — family UPDATE DELETE and subquery driven mutations, scenario 5: delete-completed-only

Task
Delete done tasks and return all remaining id,status.

Dialect: SQLite, executed with Node node:sqlite DatabaseSync. SQLite date/string functions, dynamic typing, rowid/INTEGER PRIMARY KEY, booleans-as-integers, PRAGMAs and query-plan text are SQLite-specific, not portable SQL promises.

Seed schema and data (a fresh in-memory database for every run; foreign_keys=ON)
CREATE TABLE tasks(id INTEGER PRIMARY KEY,owner TEXT,status TEXT,points INTEGER);
CREATE TABLE blocked(owner TEXT); CREATE TABLE adjustments(owner TEXT,delta INTEGER);
INSERT INTO tasks VALUES(1,'Ada','open',3),(2,'Ada','done',5),(3,'Bo','open',2),(4,'Cy','open',4),(5,'Cy','done',1),(6,'Dee','open',NULL);
INSERT INTO blocked VALUES('Bo'),(NULL); INSERT INTO adjustments VALUES('Ada',2),('Cy',-1);
