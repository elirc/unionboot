Task
Show previous value per sensor ordered by day,id, with NULL for first row; output ordered by id.

Dialect: SQLite, executed with Node node:sqlite DatabaseSync. SQLite date/string functions, dynamic typing, rowid/INTEGER PRIMARY KEY, booleans-as-integers, PRAGMAs and query-plan text are SQLite-specific, not portable SQL promises.

Seed schema and data (a fresh in-memory database for every run; foreign_keys=ON)
CREATE TABLE readings(id INTEGER PRIMARY KEY,sensor TEXT,day INTEGER,value INTEGER);
INSERT INTO readings VALUES(1,'A',1,10),(2,'A',2,20),(3,'A',2,30),(4,'A',4,40),(5,'B',1,5),(6,'B',3,15);

With the exact seed above, the first result row is {"id":1,"previous":null}.
