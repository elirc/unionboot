Q169 — family Gaps islands sequences and streaks, scenario 9: longest-nonincreasing-run

Task
Find the longest contiguous run where each battery level is less than or equal to the previous level; count initial row. Equality continues a run; an increase starts another.

Dialect: SQLite, executed with Node node:sqlite DatabaseSync. SQLite date/string functions, dynamic typing, rowid/INTEGER PRIMARY KEY, booleans-as-integers, PRAGMAs and query-plan text are SQLite-specific, not portable SQL promises.

CREATE TABLE battery(id INTEGER PRIMARY KEY,level INTEGER);
INSERT INTO battery VALUES(1,80),(2,60),(3,50),(4,50),(5,55),(6,54),(7,54),(8,70);

Concrete example
With the exact seed above, the first result row is {"longest":4}.

Expected shape
Columns (exact aliases): longest. 1 row(s); exact order below is graded. NULL is JSON null; SQLite numeric results become JavaScript numbers.
[
  {
    "longest": 4
  }
]
