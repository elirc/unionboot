ARCHITECTURE
esbuild transform per JSX component (cjs, automatic JSX), preserving external React identity, then Module._compile. jsdom globals are installed before RTL with IS_REACT_ACT_ENVIRONMENT. Cleanup between groups. Frozen data props; deterministic deferred promises, manual schedulers and sources. Pointer events use custom DOM Event fields because jsdom does not implement native PointerEvent. Observer functions are minimal injected adapters, not browser polyfills. No installation, network, live browser, actual layout, or wall-clock sleeps. Expected boundary errors may log during learner implementations.
