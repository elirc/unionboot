Each exercise exports a default component; read the spec comment in the starter and the matching tests/<id>.cjs for props. Tests run in jsdom using real DOM elements, React act, accessible queries and dispatched events. Timer exercises use the local deterministic clock.cjs (not Jest); asynchronous tests inject deferred promises and never access a network. Each test has behavior assertions; structural learning goals such as using a hook, useMemo or context additionally require self-review. No preview server. Blank starters intentionally fail. Debug/refactor prompts describe the legacy mistake rather than supplying a solved starter.
