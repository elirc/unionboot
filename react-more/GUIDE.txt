REACT MORE — RULE AND BOUNDARY SCENARIOS

200 additional exercises, IDs 584–783, 20 existing families × 10 additions.
Every family now has 15 core React scenarios: original 1–5 in react/ (100 files)
and new 6–15 here (200 files). These are honest rule/boundary variants, not
200 unrelated components. See manifest.variant and prompts/ for exact rules.

TRIPLING SCOPE
The 100 core React exercises became 300 across react/ + react-more/.
The separate 65 existing mixed-react integrations are UNTOUCHED: zero added.
They cover the first 13 families only; do not claim every mixed integration
section was tripled. Including those unchanged integrations gives 365 React
exercises total, not 495. coverage.json records family-level counts.
No original track, root manifest, root verifier, or root report is modified.

PRACTICE
1. Read prompts/ID.txt (also summarized in the JSX header).
2. Implement starters/ID.jsx; starters are deliberately blank (return null).
3. Run from unionboot: node react-more/verify.cjs --starters --id=584
   Both --id=584 and --id 584 are supported.
4. Compare solutions/ID.jsx after attempting it yourself.

VERIFY
node react-more/verify.cjs                 All 200 reference DOM groups
node react-more/verify.cjs --id=783        One reference group
node react-more/verify.cjs --starters      All starters; fresh blanks MUST fail
Exit 1 means failures; unknown IDs/flags exit 2.
Reports are written under this folder (verification-solutions.json and
verification-starters.json; targeted runs use -ID suffix). One DOM group may
contain many assertions, boundary steps and prop rerenders. Reports count
groups, not assertions. Blank negative control is expected 0 pass / 200 fail.

Dependencies come from existing unionboot/node_modules; no install needed.
The verifier compiles JSX with esbuild and runs React with Testing Library in
jsdom; async services use manually resolved promises, no timers/network.
No visual preview app is supplied. Keyboard tests assert focus/ARIA and effect
cleanup tests spy exact add/remove listener identity. Context/useReducer code
requirements also need source review: DOM equivalence cannot prove hook use.

GENERATOR
node build-react-more.cjs creates only this folder and refuses an existing one.
node build-react-more.cjs --refresh regenerates reference/test/prompt files.
Edited starters are retained; do not use refresh during active reference edits.
The preservation baseline records SHA-256 of original react and mixed-react
files, and every run checks them. It does not claim to rerun old track tests.
