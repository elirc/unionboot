ASP.NET Core Web More: W301..W600
300 exercises, 30 new families, 10 observable policy/data/boundary scenarios each.

Requires installed .NET 10 SDK and shared ASP.NET Core reference pack. No packages or network.
One project compiles solutions XOR starters; no duplicate classes. All 300 compile even with --id.
Run sequentially because bin/obj are shared.

node verify.cjs --inventory
node verify.cjs --id=W301
node verify.cjs --starters --id=301
node verify.cjs                 (full solutions, coordinator only during authoring)
node verify.cjs --starters      (full starters, coordinator only during authoring)

Exit 0 = passed; 1 = grading failure; 2 = usage/build failure.
Blank starters compile then throw NotImplementedException. Each test fragment has its own lexical block.
verification-solution.json / verification-starter.json and per-ID variants include phase/groups/results/buildPassed.
Generator refuses an existing output directory to preserve learner work.
