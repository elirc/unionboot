W531 | Request culture injected providers
Scenario 1: Injected culture fallback en-US
Semantic key: injected-culture-fallback-en-us

Call the injected IRequestCultureProvider exactly once with the original context. Use its first culture or fallback en-US when no result/cultures. Do not mutate process-wide CurrentCulture; this is request-local resolution.

Signature: public static async Task<string> Resolve(HttpContext context,IRequestCultureProvider provider)
Implement starters/W531.cs. Provided adapters only delegate to your method. Tests use real shared-framework objects without a server or network.
