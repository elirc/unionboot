Q266 — family Views projection and live query contracts, scenario 6: sqlite-view-readonly

Task
Create all_orders view and return its row count; grader verifies direct INSERT into view fails without INSTEAD OF trigger.

Dialect
SQLite 3.49.1 using Node node:sqlite DatabaseSync. JSON/FTS5, generated columns, PRAGMAs, rowid, date functions and EQP syntax/text are SQLite-specific. This is a related scenario within its family, not a claim of a wholly unrelated concept.

[
  {
    "count": 4
  }
]

Post-result integrity assertions:
[
  {
    "sql": "INSERT INTO all_orders VALUES(5,'Dee','paid',1)",
    "reject": "cannot modify.*view"
  }

Submission
