Q234 — family Generated columns and derived schema invariants, scenario 4: generated-column-write-rejection

Task
Create virtual total, insert (1,2,10), and return row. Grader checks that direct assignment to total is rejected.

Dialect
SQLite 3.49.1 using Node node:sqlite DatabaseSync. JSON/FTS5, generated columns, PRAGMAs, rowid, date functions and EQP syntax/text are SQLite-specific. This is a related scenario within its family, not a claim of a wholly unrelated concept.

Fresh seed (foreign_keys=ON)

Concrete example
The first result row on this seed is {"id":1,"total":20}.

Expected shape
Columns: id, total. Exact ordered rows, including NULL and duplicates:
[
  {
    "id": 1,
    "total": 20
  }
]

Post-result integrity assertions:
[
  {
    "sql": "UPDATE calc SET total=9",
    "reject": "generated column"
  }
]

Submission
