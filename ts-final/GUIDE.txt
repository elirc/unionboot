The verifier invokes the existing TypeScript 5.9.3 tsc CLI before any runtime test. Strict, exactOptionalPropertyTypes, noUncheckedIndexedAccess, useUnknownInCatchVariables and noImplicitReturns are enabled. Positive and @ts-expect-error negative fixtures are rebound to the selected STARTER in practice mode; solution types cannot mask a broken starter API. Fixtures are never executed. The exported solve symbol has an any guard, supplemented by concrete typed assignments and negative return-use checks; fixtures are regression coverage, not a complete proof against deliberate type escapes.

Exit codes: 0 all pass; 1 runtime failures; 2 compiler/setup failures. Unknown flags/IDs fail. Untouched starters compile successfully but every test fails with TODO exercise <id>; compiler failure is NOT a successful blank-starter control. Temporary compiler outputs live under .verify/ and are cleaned after each run. Readonly contracts do not imply runtime deep freeze unless the prompt says so.

Authoring source: ../build-ts-expansion.cjs. It refuses to overwrite either existing track so a rerun cannot destroy learner work. Root package, index and master verifier are intentionally not edited by this generator.
