W275 — Injected deterministic cache handlers
Scenario 5/10: Injected clock; TTL 5 seconds; exact expiry is stale

Cache GET-like value by exact ordinal key in injected store, using injected TimeProvider. Blank key->400 without loading. Fresh now<Expires ->200 {value,cached:true}. Missing/expired ->load once, cache for5s, return cached:false. Exact expiry is stale; loader failure must not write. Single-thread teaching store, not production concurrency. Example clock t0 first key ->load; t0+5s ->reload.
