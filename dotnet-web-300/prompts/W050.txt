W050 — Pagination query handlers
Scenario 10/10: Default size 11, max 19; strict single-value query

Parse optional page and size query parameters as single ASCII unsigned decimal int32 values >0. Defaults page1,size11; size>19->400. Duplicate/malformed values->400. Return200 JSON {page,size,total,items}; pages beyond end yield []. Use overflow-safe skip. Example ?page=2&size=2 with[1,2,3,4,5] ->items[3,4].
