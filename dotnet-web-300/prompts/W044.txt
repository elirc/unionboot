W044 — Pagination query handlers
Scenario 4/10: Default size 5, max 13; strict single-value query

Parse optional page and size query parameters as single ASCII unsigned decimal int32 values >0. Defaults page1,size5; size>13->400. Duplicate/malformed values->400. Return200 JSON {page,size,total,items}; pages beyond end yield []. Use overflow-safe skip. Example ?page=2&size=2 with[1,2,3,4,5] ->items[3,4].
