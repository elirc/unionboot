W082 — Header based request versioning
Scenario 2/10: X-Api-Version 2; missing accepted as current

Read X-Api-Version case-insensitively via HttpRequest.Headers. Missing or exactly one literal "2" ->200 JSON {version:2}. Other/empty/multiple values ->400 {error:"unsupported-version"}. No numeric normalization. Example header lower-case x-api-version:2 succeeds.
