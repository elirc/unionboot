W081 — Header based request versioning
Scenario 1/10: X-Api-Version 1; missing accepted as current

Read X-Api-Version case-insensitively via HttpRequest.Headers. Missing or exactly one literal "1" ->200 JSON {version:1}. Other/empty/multiple values ->400 {error:"unsupported-version"}. No numeric normalization. Example header lower-case x-api-version:1 succeeds.
