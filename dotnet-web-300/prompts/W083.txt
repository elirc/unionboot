W083 — Header based request versioning
Scenario 3/10: X-Api-Version 3; missing accepted as current

Read X-Api-Version case-insensitively via HttpRequest.Headers. Missing or exactly one literal "3" ->200 JSON {version:3}. Other/empty/multiple values ->400 {error:"unsupported-version"}. No numeric normalization. Example header lower-case x-api-version:3 succeeds.
