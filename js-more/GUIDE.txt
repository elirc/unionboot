JAVASCRIPT MORE: 250 NEW SCENARIOS

IDs1719..1968; 25 families x10 scenarios, not250 unrelated algorithms. Plain Node22 CommonJS, no dependencies. Every scenario has independent starter/reference/test and prompt. Cases deliberately revisit active policy, tie-break, boundary or initial-data choices. Existing tracks and root integration untouched.

PRACTICE
Read prompts/ID.txt, implement starters/ID.cjs, run node js-more/verify.cjs --starters --id=ID. Read tests before solutions. Fresh starters pass node --check but throw matching TODO exercise ID at runtime.

VERIFY
node js-more/verify.cjs --inventory
node js-more/verify.cjs --id=1719
node js-more/verify.cjs --starters --id=1719
node js-more/verify.cjs
node js-more/verify.cjs --starters
Also supports --id ID. Exit0 success/inventory, exit1 grading or inventory failure, exit2 usage/unknown ID. Unknown and repeated flags are rejected. Every selected starter, solution and test passes node --check before runtime grading. Tests use multiple assertions per group. Runtime errors include phase and stack.
Reports verification-solution.json / verification-starter.json describe the latest run, including a single-ID run; per-ID runs additionally write verification-MODE-ID.json. Inspect groups before calling a report a full-suite result. Logs reference.log and blank.log describe latest run in that mode. Suites run sequentially; no installs, services, timers or wall-clock sleeps.

DESIGN
CommonJS module export follows js-rest architecture. Added explicit prompts, strict inventory/CLI, syntax phases, JSON reports and log files. Independent oracles use brute-force/reference mathematics and no solution imports. Structural/complexity constraints need code review as well as tests. Generator semantic gate requires unique family|active-policy JSON for every family. No inactive zero-bit knob for Huffman length; no tie knob for extrema values or LCS length.

GENERATOR
node build-js-more.cjs creates js-more once. It refuses an existing js-more path; no overwrite flag. Never delete learner work to regenerate. Apply any future corrections surgically to generator and exact unchanged generated file. No grading suite is executed by generation or inventory.
