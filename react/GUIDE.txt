REACT

100 React scenario exercises across 20 interaction families. Variants revisit a family with changed constraints; these are not 100 unrelated components.

From unionboot: node react/verify.cjs
Practice one: node react/verify.cjs --starters --id=284

Tests use jsdom, React act, accessible queries and actual events. No external APIs.
Each exercise exports a component; read tests to see example props. Import a starter in your own React application for a visual preview. No preview server is included.
Do not copy reference solutions into starters unless you intentionally want solved files.
